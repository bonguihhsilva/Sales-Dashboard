<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| header Authorization → getApiKeyContext | Segredo (API key) cruza a fronteira; validação decide tenant |
| requisição sem sessão → middleware | /api/v1 deve passar sem cookie, mas NÃO deve ficar sem auth |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-7-01 | Spoofing | getApiKeyContext | mitigate | Hash SHA-256 + `timingSafeEqual` sobre buffers de tamanho igual; rejeita se prefixo/hash não batem (Task 1) |
| T-7-03 | Information Disclosure | apiKey.ts logs | mitigate | Nunca logar Authorization/rawKey; apenas `key_prefix` em erro (Task 1, verificado por grep) |
| T-7-05 | Elevation of Privilege | key revogada | mitigate | `revoked_at` consultado no banco a cada request, sem cache — revogação invalida imediatamente (Task 1) |
| T-7-08 | Denial of Service (bypass auth) | middleware | mitigate | Middleware só permite passagem; auth real no handler (Pitfall 2). Next 15.5.18 já patcheia CVE-2025-29927 (Task 3) |
| T-7-11 | Tampering | sanitizeString mal aplicado | accept | Decisão de NÃO usar sanitizeString em campos armazenados (HTML-encode corrompe dados); validação é por tipo/tamanho Zod (Task 3) |
